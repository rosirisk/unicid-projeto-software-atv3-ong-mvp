
# ONG Amigos do Bairro Gusmão - MVP
Projeto desenvolvido para a conclusão da 3ª experiência prática acadêmica da UNICID, do curso de ADS. Realizado na disciplina de Projeto de Software, tem como proposta a criação de um MVP para a fictícia ONG Amigos do Bairro Gusmão, desenvolvido em Java 21 e SQLite.

É um sistema voltado para a gestão da ONG, que abrange o cadastro de famílias para o recebimento de doações de cestas básicas e livros. Além disso, deverá auxiliar no controle de estoque das referidas doações. O projeto é voltado para o público-alvo (famílias de baixa renda do bairro). A intenção é simular a operação da ONG (coerente com regras realistas), integrando as funcionalidades necessárias e as regras de negócio adaptadas ao contexto da instituição.
